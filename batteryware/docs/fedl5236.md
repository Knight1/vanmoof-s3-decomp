# FEDL5236 (LAPIS/ROHM ML5236) — register reference & firmware configuration

Companion to `hardware.md`. This file documents the battery analog
front-end (AFE) as the datasheet defines it **and** exactly how
batteryware programs it: which register, what value, decoded bit-by-bit,
and from where in the firmware.

> Datasheet: `reference/FEDL5236.pdf` (FEDL5236-10, 2024-01-09).
> The doc number is **FEDL5236**; the part is **ML5236**.

## 1. Chip identity

The **ML5236** is a LAPIS Technology (now ROHM) **analog front-end for
5–14-series-cell Li-ion battery protection**. Integrated functions:

- 12-bit SAR ADC, shared between per-cell voltage and pack current.
- Per-cell voltage monitor (±10 mV typ @ 4 V), 2 ms/cell.
- Pack current monitor: ISP–ISM differential × 12 or × 60, then the ADC.
- Autonomous short-circuit protection (turns off the external Nch
  charge/discharge FETs without MCU intervention).
- Built-in per-cell balancing switches (≈6 Ω on-resistance).
- Charge/discharge FET gate drivers (high-side Nch).
- Two thermistor (TEMP1/TEMP2) inputs; PSNS/DFS pin voltage sense.
- Overvoltage protection vs a register threshold.
- Built-in 3.3 V regulator for the host MCU.

> **Correction for `hardware.md`:** the existing note calls this a
> "Fortior Tech FEDL5236 fuel gauge." It is **not** Fortior and it is not
> a fuel gauge — it is the LAPIS/ROHM **ML5236 protection AFE**. The
> coulomb-counting / RSOC "fuel gauge" logic lives in the MCU firmware
> (`fuel_gauge.c`), reading raw cell/current values from this AFE.

### Host interface

- **SPI mode 0**, MSB-first, dedicated `VSPI` rail (5 V tolerant). Data in
  on SDI sampled on SCK rising edge; data out on SDO on SCK falling edge.
  `/CS` must return high after every transaction.
- Frame = `[EC | A5..A0 | RW]` address byte, then data. **RW=0 write,
  RW=1 read.** Write data is always 1 byte; read length is specified by
  the command. **EC=1** appends a 1-byte CRC (poly `X⁸+X²+X+1` = `0x07`,
  CRC reset to `0xFF` on `/CS` high); the AFE only commits a write when
  the received CRC matches.
- A `/INTO` (active-low) interrupt line and a busy/data-ready indicator
  the firmware polls on **GPIOC pin 12** (`PC12`, mask `0x1000`, base
  `0x50000800`) — see `bms_init.c::wait_for_chip_ready`.

> **Decomp naming note:** the firmware's SPI wrappers are misnamed
> `smbus_write_reg(reg, val, mask)` / `smbus_read(addr, count)` /
> `smbus_read_nack(addr, val)` (in `spi.c`). The bus is SPI, not SMBus.
> The `mask` argument of `smbus_write_reg` is a write bit-mask (only the
> POWER write at reg `0x0C` uses anything other than `0xFF` — it uses
> `0x7F` to leave the read-only PUPIN bit alone).
>
> **CRC note:** `crc.c::crc8_for_smbus` is implemented with **init
> `0x00`**, whereas the datasheet specifies CRC reset to **`0xFF`**. This
> is flagged for the code phase; it does not affect the register map.

## 2. Control register map (datasheet)

`R/W` and `Default` are the datasheet values. Register addresses equal
the decimal `reg` numbers used in the firmware (e.g. `smbus_write_reg(14,…)`
→ `0x0E`).

| Adr | Name | R/W | Def | Description |
| --- | --- | --- | --- | --- |
| `00` | NOOP | R/W | `00` | User scratch — **no hardware effect** |
| `01` | INT_EN1 | R/W | `00` | IRQ enable: ESM ETM EIM EVM (measurement-complete) |
| `02` | INT_EN2 | R/W | `00` | IRQ enable: EWDT ECKSP ECRC ESC EOV |
| `03` | INT_REQ1 | R/W | `00` | IRQ request flags QSM QTM QIM QVM (write 0 to clear) |
| `04` | INT_REQ2 | R/W | `00` | IRQ request flags QWDT QCKSP QCRC QSC QOV (write 0 to clear) |
| `05` | VMEAS | R/W | `00` | Cell-voltage measurement control (VM, SCAN, VC3..0) |
| `06` | IMEAS | R/W | `00` | Current measurement control (IM, ENIM, ZERO, GIM) |
| `07` | TMEAS | R/W | `00` | Temperature measurement control (TM, TSEL, TDRV) |
| `08` | SMEAS | R/W | `00` | PSNS/DFS voltage measurement control (SM, ENSM, SSEL, PU, PD) |
| `09` | FET | R/W | `00` | Charge/discharge FET control (CF, DF) |
| `0A` | CBALL | R/W | `00` | Cell balancing switches, cells 1–8 (SW1..SW8) |
| `0B` | CBALH | R/W | `00` | Cell balancing switches, cells 9–14 (SW9..SW14) |
| `0C` | POWER | R/W | `00` | Power-save/down (PSV, PDWN); read-only PUPIN bit |
| `0D` | STATUS | R | `00` | INT CKSP WDT OV CBAL PSV CF DF |
| `0E` | SCWDT | R/W | `00` | Short-circuit threshold + watchdog (ENWD, WDT1:0, ENSC, SC1:0) |
| `0F` | SETOV | R/W | `00` | OV-detect config (ENOV, SLT1:0, CN2:0) |
| `10` | OVDETL | R/W | `FF` | OV threshold, low 8 bits |
| `11` | OVDETH | R/W | `0F` | OV threshold, high 4 bits |
| `12`–`2D` | VCELL1L..VCELL14H | R | `00` | Per-cell ADC results (L=low 8, H=high 4); even=L, odd=H |
| `2E`/`2F` | CURL/CURH | R | `00` | Pack current ADC result (16-bit) |
| `30`–`33` | TEMP1L..TEMP2H | R | `00` | Thermistor ADC results |
| `34`/`35` | SNSL/SNSH | R | `00` | PSNS/DFS pin voltage ADC result (1/32 of pin level) |

### Bit layouts of the registers the firmware writes

```
INT_EN1 (01)   [ 7  6  5  4 | ESM ETM EIM EVM ]   (en measurement-complete IRQs)
INT_EN2 (02)   [ 7  6  5 |EWDT ECKSP ECRC ESC EOV ]
INT_REQ1(03)   [ 7  6  5  4 | QSM QTM QIM QVM ]    (write 0 to clear a flag)
INT_REQ2(04)   [ 7  6  5 |QWDT QCKSP QCRC QSC QOV ]
VMEAS  (05)    [ VM  -  - SCAN| VC3 VC2 VC1 VC0 ]  (VM=start/busy)
IMEAS  (06)    [ IM  -  - ENIM|  -   - ZERO GIM ]  (IM=start/busy, GIM gain 12×/60×)
TMEAS  (07)    [ TM  -  -  -  |  -   -  TSEL TDRV]
SMEAS  (08)    [ SM  -  - ENSM|  -  SSEL  PU  PD ]  (PD=500k PSNS pulldown, PU=2M DFS pullup)
FET    (09)    [ 7  6  5  4  3  2 | CF  DF ]        (1=FET on; SC/WDT events auto-clear both)
CBALL  (0A)    [SW8 SW7 SW6 SW5 SW4 SW3 SW2 SW1]
CBALH  (0B)    [ -   - SW14 SW13 SW12 SW11 SW10 SW9]
POWER  (0C)    [PUPIN - - PDWN| -  -  -  PSV ]      (PUPIN read-only; PDWN=power-down, PSV=power-save)
SCWDT  (0E)    [ENWD - WDT1 WDT0|ENSC - SC1 SC0]    (WDT period 1/2/4/8 s; SC thr 50/100/150/200 mV)
SETOV  (0F)    [ENOV - SLT1 SLT0| - CN2 CN1 CN0]    (CN=consecutive-detect count 1..128)
OVDET (10/11)  12-bit threshold OVD11..OVD0, compared against each cell's ADC code
```

## 3. How batteryware configures the AFE

### 3.1 Power-on init — `bms_init.c::bms_init()` (OEM `FUN_08004d04`)

Phase 1 programs the full control-register set. Every line is one
`smbus_write_reg(reg, value, mask)`:

| Order | reg | Name | val | Decoded meaning |
| --- | --- | --- | --- | --- |
| 1 | `00` | NOOP | `AA` | comms handshake / link check (NOOP has no HW effect) |
| 2 | `00` | NOOP | `55` | second handshake byte |
| 3 | `09` | FET | `00` | both FETs **off** (CF=0, DF=0) |
| 4 | `0A` | CBALL | `00` | cells 1–8 balancing **off** |
| 5 | `0B` | CBALH | `00` | cells 9–14 balancing **off** |
| 6 | `0C` | POWER | `00` (mask `7F`) | **normal** state (PSV=0, PDWN=0); mask preserves read-only PUPIN |
| 7 | `0E` | SCWDT | `9A` | ENWD=1 (WDT run), WDT=2 s, ENSC=1 (SC run), SC thr=**150 mV** |
| 8 | `10` | OVDETL | `FF` | OV threshold low byte |
| 9 | `11` | OVDETH | `0F` | OV threshold high nibble → **OVD = 0xFFF (max, 4095)** |
| 10 | `0F` | SETOV | `00` | ENOV=0 → **OV detection left OFF**, CN=1 scan, SLT=1 s |
| 11 | `01` | INT_EN1 | `0F` | enable **all four** measurement-complete IRQs (ESM ETM EIM EVM) |
| 12 | `02` | INT_EN2 | `02` | enable **short-circuit** IRQ (ESC) |
| 13 | `03` | INT_REQ1 | `00` | clear measurement IRQ request flags |
| 14 | `04` | INT_REQ2 | `00` | clear protection IRQ request flags |
| 15 | `08` | SMEAS | `01` | PD=1 → connect 500 kΩ PSNS pull-down (settle before measuring) |

Notes:

- **OV protection is armed maxed-out and disabled at init.** The threshold
  is `0xFFF` (no cell can exceed it) and `SETOV.ENOV=0`. Overvoltage
  monitoring, if used, must be enabled later by firmware.
- **150 mV / 1 mΩ shunt ⇒ ~150 A short-circuit trip**, 2 s watchdog.
- The handshake writes to NOOP (`0xAA`, `0x55`) verify the SPI link only.

Phase 2 (status acquisition, retry until a status word latches):
- `smbus_write_reg(06, 92)` → IMEAS `0x92`: IM=1 start, ENIM=1 amp on,
  ZERO=1 → run **zero-current compensation** (16× averaged).
- `smbus_read(03, 2)` reads INT_REQ1 (+ a second byte); low nibble gates
  re-clearing INT_REQ1 (reg 3) / INT_REQ2 (reg 4).
- if low-nibble bit 1 set: `smbus_read(0x2E, 2)` reads CURL/CURH and packs
  a 16-bit current/status word at SRAM `0x20002878`.

Phase 3 (cell-voltage acquisition, retry until sentinel set):
- `smbus_write_reg(05, 99)` → VMEAS `0x99`: VM=1 start, SCAN=1,
  VC3:0=`1001` → **"cell 5 to cell 14 scanned"** = **10 cells**.
- on completion (status low-nibble bit 0): `smbus_read(0x1A, 2×cell_count)`
  reads **from VCELL5L (`0x1A`)** for `cell_count` cells. Each 12-bit raw
  code is scaled `raw × 5000 / 4095` (mV) into the cell table at
  `0x200027D4`.

> **Pack topology fact (derived):** the scan mask (`0x99` ⇒ cells 5–14)
> and the read base (`0x1A` = VCELL5L) together confirm a **10S pack
> wired to V5..V14**, with V0..V4 tied to GND per the datasheet "Cell
> Connection Table" for a 10-cell pack. `cell_count` comes from
> `s_cfg_base[4]` (`0x200028D4`).

### 3.2 Reconfigure — `fuel_gauge.c::bms_configure(cfg)` (OEM `FUN_…`)

Re-programs regs 3–9 with the runtime config byte:

| reg | val | meaning |
| --- | --- | --- |
| `03` | `00` | clear INT_REQ1 (conditional, gated on a flag + GPIOC13) |
| `04` | `00` | clear INT_REQ2 (same gate) |
| `05` | `00` | VMEAS stop |
| `06` | `00` | IMEAS stop |
| `07` | `00` | TMEAS stop |
| `08` | `01` | SMEAS: PD pull-down on |
| `09` | `cfg` | **FET control** — `cfg` bit0=DF (discharge), bit1=CF (charge) |

So the firmware's "BMS config byte" is, at the hardware level, the
**FET register** value: it directly drives charge/discharge FET enable.

### 3.3 Measurement helpers (`fuel_gauge.c`)

| Call | reg | Meaning |
| --- | --- | --- |
| `smbus_write_reg(08, 0x91)` | SMEAS | SM=1 start, ENSM=1 circuit on, PD=1 → measure **PSNS pin voltage** |
| `smbus_write_reg(06, 0x90)` | IMEAS | IM=1, ENIM=1, ZERO=0 → measure **pack current** (no zero-comp) |
| `smbus_write_reg(06, 0x92)` | IMEAS | as above + ZERO=1 → **zero-current compensation** |
| `smbus_read(0x2E, 2)` | CURL/CURH | read 16-bit pack current |
| `smbus_read(0x34, 2)` | SNSL/SNSH | read PSNS/DFS (1/32 pin) — used as pack-voltage proxy |
| `smbus_read(0x01, 2)` | INT_EN1/2 | read interrupt-enable readback |
| `smbus_read(0x03, 2)` + write 03/04 = 0 | INT_REQ | poll & clear interrupt requests |

### 3.4 Cell-balance clear — `state_handlers.c` (~line 715)

`smbus_read(10, 2)` reads back **CBALL (`0x0A`) + CBALH (`0x0B`)** — the
active balancing-switch bitmap — and stores the two bytes at SRAM
`0x20002820`. When the BMS-config bit 9 is set it clears it and writes
`CBALL=0` / `CBALH=0` to turn **all cell-balancing switches off**.

> **Discrepancy flagged:** both the decomp comment here and `hardware.md`
> call `0x20002820` "FEDL5236 status word" and call reg 10 the "status
> register." Per the datasheet, reg `0x0A`/`0x0B` are **CBALL/CBALH**
> (balancing-switch state), not STATUS (which is reg `0x0D`). The value
> read is the balancing-switch readback, not the STATUS register. Worth
> renaming when this handler is verified.

### 3.5 Shipping power-down — `state_handlers.c::button_entry_check()` (OEM `FUN_080050ac`)

The shipping/bootloader power-down handshake:

1. `PB9 = 0` (external charge MOSFET off).
2. `smbus_write_reg(08, 0x01)` then `smbus_write_reg(08, 0x91)` → PSNS
   pull-down, then start PSNS measurement.
3. Poll `smbus_read(0x34, 2)` (SNS) and scale `raw × 19536 / 1000` to mV;
   the 19.536 factor folds the AFE's 1/32 SNS divider, the 12-bit ADC LSB,
   and the external pack divider into a pack-voltage estimate.
4. Once the pack is at/below 10 000 (≈10 V): wait on **POWER.PUPIN**
   (`smbus_read(0x0C, 1)`, bit 7 = `/PUPIN` must read high), then issue
   power-down via `smbus_read_nack(0x0C, 0x10)` → **POWER write `0x10`,
   i.e. PDWN=1**.
5. Sample the button on `PA11` to print `POWER_DOWN_Finish` / `_Error`.

This matches the datasheet power-down preconditions exactly: FETs off +
verify no charger present (PSNS) + `/PUPIN` high before setting PDWN.

## 4. Value decode — every byte written, bit by bit

Every distinct value the firmware writes to the AFE, expanded to bits.
Bit 7 is MSB. `—` = reserved/unused; `·` = bit clear with no named
function in that value.

### NOOP (`0x00`)

| Value | Bits | Meaning |
| --- | --- | --- |
| `0xAA` | `1010 1010` | no hardware effect — SPI link check (alternating pattern) |
| `0x55` | `0101 0101` | no hardware effect — second link-check byte |

### INT_EN1 (`0x01`) — measurement-complete IRQ enables

| Value | `· · · · ESM ETM EIM EVM` | Meaning |
| --- | --- | --- |
| `0x0F` | `0000 1111` | **all four** enabled: PSNS(ESM)+temp(ETM)+current(EIM)+cell-voltage(EVM) IRQs on |

### INT_EN2 (`0x02`) — protection IRQ enables

| Value | `· · · EWDT ECKSP ECRC ESC EOV` | Meaning |
| --- | --- | --- |
| `0x02` | `0000 0010` | **ESC only** — short-circuit IRQ enabled; OV/CRC/clock-stop/WDT IRQs off |

### INT_REQ1/2 (`0x03`/`0x04`) — clear request flags

| Value | Meaning |
| --- | --- |
| `0x00` | clear all request flags (writing `0` to a bit clears it; writing `1` is ignored, so `0x00` clears every flag at once) |

### VMEAS (`0x05`) — cell-voltage measurement

| Value | `VM · · SCAN VC3 VC2 VC1 VC0` | Meaning |
| --- | --- | --- |
| `0x99` | `1001 1001` | VM=1 start, SCAN=1, VC=`1001` → **scan cells 5→14** (10 cells) |
| `0x00` | `0000 0000` | stop / idle |

### IMEAS (`0x06`) — pack-current measurement

| Value | `IM · · ENIM · · ZERO GIM` | Meaning |
| --- | --- | --- |
| `0x90` | `1001 0000` | IM=1 start (16× avg), ENIM=1 amp on, ZERO=0 → **measure current**, GIM=0 → ×12 gain |
| `0x92` | `1001 0010` | as `0x90` but ZERO=1 → **zero-current compensation** (ISP/ISM internally grounded) |
| `0x00` | `0000 0000` | stop / idle |

### TMEAS (`0x07`) — temperature measurement

| Value | `TM · · · · · TSEL TDRV` | Meaning |
| --- | --- | --- |
| `0x00` | `0000 0000` | stopped; TSEL=0 (TEMP1), TDRV=0 (Hi-Z) — temp sensing currently unused |

### SMEAS (`0x08`) — PSNS/DFS pin-voltage measurement

| Value | `SM · · ENSM · SSEL PU PD` | Meaning |
| --- | --- | --- |
| `0x01` | `0000 0001` | PD=1 → connect 500 kΩ PSNS pull-down only (settle, no measure) |
| `0x91` | `1001 0001` | SM=1 start, ENSM=1 circuit on, SSEL=0 (PSNS), PD=1 → **measure PSNS** |

### FET (`0x09`) — charge/discharge FET control

| Value | `· · · · · · CF DF` | Meaning |
| --- | --- | --- |
| `0x00` | `0000 0000` | both FETs **off** |
| `cfg` | `…… CF DF` | runtime config byte drives the FETs directly: bit0=DF (discharge), bit1=CF (charge). e.g. `0x03`=both on, `0x01`=discharge only, `0x02`=charge only |

> SC detection and double-WDT-overflow auto-clear CF and DF in hardware;
> firmware must re-assert them via this register after recovery.

### CBALL/CBALH (`0x0A`/`0x0B`) — cell-balancing switches

| Value | Meaning |
| --- | --- |
| `0x00` | all balancing switches off (CBALL=cells 1–8 SW1..SW8; CBALH=cells 9–14 SW9..SW14) |

### POWER (`0x0C`) — power-save / power-down

| Value | `PUPIN · · PDWN · · · PSV` | Meaning |
| --- | --- | --- |
| `0x00` (mask `0x7F`) | `0000 0000` | normal state (PSV=0, PDWN=0); mask `0x7F` writes bits 0–6 only, leaving read-only PUPIN (bit7) untouched |
| `0x10` | `0001 0000` | PDWN=1 → **power-down** (shipping); written via `smbus_read_nack(0x0C,0x10)` after PUPIN handshake |

### SCWDT (`0x0E`) — short-circuit threshold + watchdog

| Value | `ENWD · WDT1 WDT0 ENSC · SC1 SC0` | Meaning |
| --- | --- | --- |
| `0x9A` | `1001 1010` | ENWD=1 (WDT run), WDT=`01`→**2 s** period, ENSC=1 (SC run), SC=`10`→**150 mV** (≈150 A @ 1 mΩ) |

### SETOV (`0x0F`) — overvoltage-detect config

| Value | `ENOV · SLT1 SLT0 · CN2 CN1 CN0` | Meaning |
| --- | --- | --- |
| `0x00` | `0000 0000` | ENOV=0 → **OV detection OFF**; SLT=`00`→1 s power-save scan interval; CN=`000`→trip on 1 scan |

### OVDETL/OVDETH (`0x10`/`0x11`) — overvoltage threshold

| Regs | Value | Meaning |
| --- | --- | --- |
| `0x10`=`0xFF`, `0x11`=`0x0F` | OVD[11:0] = `0xFFF` | threshold = **4095 = max**; no 12-bit cell ADC code can exceed it (OV effectively disarmed, consistent with SETOV.ENOV=0) |

### Summary of the steady-state init

After `bms_init` Phase 1 the AFE is left: FETs off, no balancing, normal
power, **watchdog armed (2 s)**, **short-circuit armed (150 mV)**,
**overvoltage NOT armed** (threshold maxed + ENOV=0), all
measurement-complete IRQs + the short-circuit IRQ enabled, request flags
cleared, PSNS pull-down connected.
